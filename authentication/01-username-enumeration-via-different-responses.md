# Username Enumeration via Different Responses

**Платформа:** PortSwigger Web Security Academy
**Категория:** Authentication
**Дата:** 17 октября 2026
**Статус:** ✅ Решено

## Описание уязвимости
Приложение возвращает разные ответы в зависимости от того, существует ли введенное имя пользователя. Это позволяет злоумышленнику провести перечисление (enumeration) валидных логинов, что значительно упрощает последующий подбор пароля (brute-force).

## Шаги воспроизведения

### 1. Поиск валидного имени пользователя
1. Отправляем запрос `POST /login` с неверными данными в Burp Intruder.
2. В Positions оставляем метку `§` только вокруг параметра `username`, пароль оставляем статичным.
3. В Payloads загружаем список потенциальных логинов.
4. Запускаем атаку (тип Sniper).
5. Сортируем результаты по столбцу `Length`. Видим, что один из ответов отличается по длине (например, 3354 байта вместо 3352).
6. В Response этого запроса видим сообщение `Incorrect password` (вместо `Invalid username`).
7. **Найденный логин:** `accounting`

### 2. Подбор пароля
1. Отправляем запрос `POST /login` заново в Intruder.
2. В Positions меняем статичное значение `username` на найденное (`accounting`).
3. Добавляем метку `§` вокруг параметра `password`.
4. В Payloads загружаем список паролей.
5. Запускаем атаку.
6. Сортируем результаты по столбцу `Status`. Все запросы возвращают `200 OK`, кроме одного, который возвращает `302 Found` (редирект на страницу профиля).
7. **Найденный пароль:** `1234567890`

## Результат
Успешный вход в систему под учетной записью `accounting` и решение лабораторной работы.

## Защита (Remediation)
1. **Унифицировать ответы:** При неверном логине или пароле сервер должен возвращать абсолютно одинаковый текст ошибки (например, "Invalid username or password").
2. **Унифицировать время ответа:** Использовать константное время обработки запросов или добавить случайную задержку, чтобы исключить timing-атаки.
3. **Ограничение попыток:** Внедрить rate-limiting (например, блокировка на 15 минут после 5 неверных попыток) и/или капчу.
