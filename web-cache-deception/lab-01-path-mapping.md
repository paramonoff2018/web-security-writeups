# Lab: Exploiting path mapping for web cache deception

**Ссылка:** https://portswigger.net/web-security/web-cache-deception/lab-wcd-exploiting-path-mapping
**Статус:** ✅
**Дата:** 2026-10-24

## Что уязвимо

Расхождение в парсинге URL пути между origin-сервером и кэшем:

- **Origin-сервер** использует REST-style mapping: абстрагирует путь и игнорирует лишние сегменты после `/my-account`. Запрос `/my-account/abc` возвращает те же данные, что и `/my-account`.
- **Кэш** использует правило на основе расширения `.js`: считает ответ статическим ресурсом и кэширует его.

В результате запрос `/my-account/wcd.js` возвращает динамические данные пользователя, но кэш сохраняет их как статический файл. Атакующий заставляет жертву перейти по такому URL, после чего забирает закэшированный ответ с данными жертвы.

## Разведка

1. Залогинился как `wiener:peter`. На странице `/my-account` отображается API key.
2. В Burp Repeater отправил `GET /my-account/abc` — ответ всё ещё содержит API key. Значит, origin игнорирует лишний сегмент.
3. Отправил `GET /my-account/abc.js` — в ответе появились заголовки:
   - `X-Cache: miss`
   - `Cache-Control: max-age=30`
   - `Age: 0`
4. Повторно отправил тот же запрос в течение 30 секунд — `X-Cache: hit`. Кэш сохранил ответ с моим API key.

## Защита

- Настроить кэш так, чтобы он не переопределял заголовок `Cache-Control` от origin-сервера (`no-store` или `private` для динамических страниц).
- Убедиться, что кэш не кэширует ответы для путей, которые origin-сервер считает динамическими, даже если они заканчиваются на статическое расширение.
- Использовать строгую валидацию пути: не игнорировать лишние сегменты после известных эндпоинтов.
- Не полагаться на расширение файла как единственный признак статического ресурса.

## Уроки

- Всегда проверять, как origin и кэш по-разному интерпретируют URL (path mapping, delimiters, normalization).
- Кэш-бастер (уникальный query string) помогает избежать получения закэшированных ответов при тестировании.
- Для проверки кэша смотреть на `X-Cache`, `Cache-Control`, `Age` и разницу во времени ответа.
