# 🛠️ Инструменты и расширения (Burp Suite Community)

## Установка
Все расширения ставятся через **Extensions → BApp Store** → поиск → **Install**.

## Рабочие расширения (Community Edition)

| Расширение | Назначение |
| :--- | :--- |
| **Turbo Intruder** | Высокоскоростной брутфорс, Race Conditions (Single-packet attack). |
| **Logger++** | Улучшенная история запросов, фильтры, поиск, экспорт. |
| **Param Miner** | Поиск скрытых параметров и заголовков. |
| **HTTP Request Smuggler** | Поиск и эксплуатация HTTP Request Smuggling. |
| **JWT Editor** | Редактирование, подпись и проверка JWT-токенов. |
| **Hackvertor** | Кодирование/декодирование данных (URL, HTML, Base64 и др.). |

## Исключено (не устанавливается в текущей сборке)
- **Autorize** — кнопка Install неактивна (отсутствуют зависимости/устарело).
- **JS Link Finder** — кнопка Install неактивна.

## Ограничения Community
- **Нет Burp Collaborator** → расширения, требующие внешних взаимодействий (например, Collaborator Everywhere), не работают.
- **Нет встроенного сканера** → расширения, зависящие от Burp Scanner, работать не будут.
