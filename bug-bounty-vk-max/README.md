# Bug Bounty: VK MAX

## 🚨 Scope (Область действия)
* Домены: *.oneme.ru, *.max.ru
* Специфичные хосты: calls.okcdn.ru, videostun*.okcdn.ru, call*-*.vkuser.net, videowebrtc.okcdn.ru
* Сферум (если влияет на MAX): frontend.sferum-dev.ru, platform-api.sferum-dev.ru, *.sferum-platform.ru, *.sferum-dev.ru

## ⚠️ Правила безопасности (Ограничения)
* **Rate Limit:** Максимум 4 запроса в секунду.
* **Запрещено:** DoS, флуд, тяжелые сканеры, инкрементный перебор ID (1, 2, 3...).
* **Тестирование:** Только на своих аккаунтах.
* **IDOR (MAX для бизнеса):** Использовать только ID профиля `1073626623` и ID организации `9522951`.

## 💰 Приоритетные цели
1. Доступ к приватной переписке (Server-Side).
2. IDOR с утечкой конфиденциальных данных.
3. Нарушение ролевой модели в каналах.
4. Race Condition (состояния гонки) при переводах/отправках.
5. SSRF с чтением ответа сервера.

## 🛠️ Наш стек инструментов
* **Burp Suite** (перехват и модификация)
* **Subfinder / Assetfinder** (пассивная разведка)
* **httpx / ffuf** (активное сканирование с лимитами)
* **Python / C++** (кастомные скрипты)
