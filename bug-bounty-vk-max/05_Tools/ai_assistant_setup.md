# Настройка ИИ-ассистента (VS Codium + Continue)

## Контекст
В проекте используется локальный ИИ-ассистент (расширение Continue) для анализа кода, поиска уязвимостей и написания скриптов.

## Стек
* **Редактор:** VS Codium (установлен в Windows).
* **Расширение:** Continue.
* **Основная модель:** DeepSeek V4 Pro (xhigh) — для глубокого анализа JS-кода и сложных задач.
* **Вспомогательные модели:** OpenAI GPT-4.1, o3 (для работы с картинками).
* **Провайдер:** Kodik Router (прокси для доступа к API).

## Задачи для ИИ
1. **Анализ JS-бандлов:** Поиск скрытых эндпоинтов (API), особенно связанных с ролями (`role`, `owner`, `invite`).
2. **Написание эксплойтов:** Генерация Python-скриптов (asyncio, httpx) для Race Condition.
3. **Разбор кода:** Объяснение логики работы приложения (KPHP, Next.js).

## ⚠️ Важное правило безопасности
Файл конфигурации Continue (`config.yaml`) с API-ключами **запрещено** пушить в Git. Он добавлен в `.gitignore`. Ключи хранятся только локально на машине исследователя.
