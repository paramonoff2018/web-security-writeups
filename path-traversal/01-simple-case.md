# Path Traversal (Обход файловых путей) — Простой пример

**Платформа:** PortSwigger Web Security Academy
**Сложность:** Apprentice (Ученик)
**Статус:** ✅ Solved

## 📌 Описание уязвимости

Уязвимость возникает, когда приложение использует введенные пользователем данные для формирования пути к файлу, но не проверяет наличие символов выхода из директории (`../`). 

Это позволяет злоумышленнику читать произвольные файлы на сервере (LFI) или даже записывать их (если есть функционал загрузки).

## 🎯 Цель лабы
Получить содержимое файла `/etc/passwd` через уязвимость в отображении картинок товаров.

## 🛠️ Вектор атаки (Шаги)

1. **Разведка:** Открываем страницу магазина, выбираем любой товар.
2. **Перехват:** В Burp Suite перехватываем запрос на загрузку изображения товара.
3. **Анализ:** Запрос выглядит так:
   ```http
   GET /image?filename=1.jpg HTTP/2

Параметр filename передает имя файла, который нужно загрузить. Сервер, скорее всего, ищет его в папке /var/www/images/.

Эксплуатация: Меняем значение параметра на payload:

http
GET /image?filename=../../../etc/passwd HTTP/2
Результат: В ответе сервер возвращает содержимое файла /etc/passwd (список пользователей Linux).

🧠 Логика работы ../
Сервер формирует путь: /var/www/images/ + ../../../etc/passwd

Первый ../ выходит из images в www

Второй ../ выходит из www в var

Третий ../ выходит из var в корень /

Итоговый путь: /etc/passwd

🛡️ Как защититься (Mitigation)
Whitelist (Белый список): Использовать строгий список разрешенных имен файлов.

Санитизация: Удалять или экранировать символы ../ и \ из пользовательского ввода.

Изоляция: Ограничить права веб-сервера (запускать его в контейнере с правами только на папку с картинками).

💡 Заметки для пентеста
/etc/passwd — это только начало. На реальных пентестах через эту дыру ищут конфиги (.env, config.php), приватные ключи SSH (~/.ssh/id_rsa) и логи.

Если Wappalyzer показывает старый PHP или Node.js — обязательно проверяй этот вектор в эндпоинтах загрузки/скачивания файлов.
