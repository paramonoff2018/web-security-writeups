# Арсенал инструментов — VK Видео (Bug Bounty)

Правило: 10 req/s, автоскан запрещён, только ручная проверка (PoC), только свои аккаунты.

---

## 1. УСТАНОВЛЕНО И ПРИМЕНЯЕТСЯ

**Перехват / анализ:**
- **Burp Suite Community** — перехват, Repeater (ручные запросы), Intruder (перебор), Match&Replace (`X-Bug-Bounty`).
- **Chrome DevTools** — Network, Application (JS-бандлы), Sources.
- **Wappalyzer** — определение стека (нашли: Svelte, VKUI, PHP/KPHP, Joomla, Sentry).

**Парсинг / скрипты:**
- **jq** — парсинг HAR, JSON-ответов.
- **curl** — ручные запросы для воспроизведения (нужно для отчёта).
- **DeepSeek-агент** (`~/ai-agent`) — только для анализа JS-кода и генерации идей (без автоматического поиска уязвимостей).

---

## 2. НУЖНО УСТАНОВИТЬ И ПРИМЕНИТЬ (Recon & Fuzzing)

**Приоритет 1 (сейчас):**
- **LinkFinder** — вытаскивает скрытые API-эндпоинты из JS-файлов (Svelte-бандлы).
  - *Как применять:* Скачать `.js` файлы из Burp, прогнать через скрипт, найти пути `/method/` и `/api/`.
- **arjun** — поиск скрытых параметров в API.
  - *Как применять:* `arjun -u <API_URL> -m POST --headers "Cookie: <...>" -t 2 --rate-limit 5`.
- **ffuf** — фаззинг директорий/эндпоинтов (вручную, 10 req/s).
  - *Как применять:* Только если есть конкретный список слов, не «всё подряд».

**Приоритет 2 (по мере необходимости):**
- **interactsh-client** — для проверки Blind SSRF (если найдем параметры с URL).
- **Gf-Patterns** — поиск уязвимых паттернов в URL.

---

## 3. ЧТО НЕ ПРИМЕНЯЕТСЯ (Запреты VK)

- **Nuclei / Nikto / Acunetix** — автосканеры (запрещены, отчёты без PoC не принимают).
- **nmap** — сканирование портов не оплачивается и не нужно для веба.
- **gobuster / dirb / hydra** — агрессивный брутфорс (нарушает лимиты).
- **Metasploit** — автоэксплуатация.
