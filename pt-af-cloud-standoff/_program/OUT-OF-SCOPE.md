# Out-of-Scope — PT AF Cloud

## Явно запрещено
- DoS/DDoS, stress/load testing, resource exhaustion
- Массовые перезапуски agents/borders или деградация control plane
- Атаки, наносящие вред целостности и доступности сервисов
- Воздействие на учётные записи других пользователей без разрешения
- Использование malware, ransomware, reverse shells с persistence, cryptominers, destructive payloads
- Инструменты, автоматически генерирующие значительные объёмы трафика
- Социальная инженерия (фишинг, вишинг), спам-рассылки
- Физические атаки
- Pivot во внутреннюю инфраструктуру PT, клиентов, партнёров
- Сканирование/эксплуатация инфраструктуры клиентов
- Массовая выгрузка данных, логов, отчётов, traffic dumps, telemetry, PII
- Атаки на реальные приложения клиентов, защищаемые PT Cloud AF
- Публичное раскрытие уязвимости без согласования

## Не оплачивается
- Отчёты, полностью сгенерированные сканерами без ручной проверки
- Раскрытие несекретной информации (версии ПО, IP, DNS, открытые порты)
- TLS/SSL best practice findings без сценария атаки
- Отсутствие rate limit или brute-force protection без метода, существенно превосходящего обычный перебор
- Публичные 0-day/1-day без нового PT Cloud AF-specific влияния
- Уязвимости, заблокированные СЗИ, без демонстрации обхода
- Дубликаты
