# PT AF Cloud — Правила программы

> Полный текст — в файле «PT AF Cloud.txt» (корень репозитория).

## Требования к участникам
- 18+ (14–18 — с письменным согласием родителей)
- Соблюдать правила PT и Standoff 365
- Не получать доступ к чужим данным, не раскрывать конфиденциальное
- Не разглашать уязвимость до публикации PT

## Запрещено
- DoS/DDoS, stress/load, resource exhaustion
- Массовые рестарты agents/borders
- Атаки на целостность/доступность (сообщить PT — проведут в тестовой среде)
- Воздействие на чужие учётки без разрешения
- Использование уязвимости в личных целях
- Malware/ransomware/reverse shell с persistence/cryptominers/destructive payloads вне выделенного тестового тенанта
- Автоматические сканеры, генерирующие большой трафик
- Соц. инженерия, фишинг, вишинг, спам
- Физические атаки
- Pivot во внутреннюю инфраструктуру PT/клиентов/партнёров
- Сканирование/эксплуатация инфраструктуры клиентских приложений
- Массовая выгрузка данных/логов/отчётов/telemetry/ПДн
- Атаки на реальные приложения клиентов вне тестовых целей
- Публичное раскрытие без согласования

## Не выплачивается
- Отчёты автосканеров без ручной проверки
- Несекретная информация (версии, метрики, IP/DNS/порты)
- Known vuln по версии без эксплуатации в PT Cloud AF
- TLS/SSL best practice без PoC
- Отсутствие rate limit без существенно более эффективного метода
- Публичные 0-day/1-day без нового PT-специфичного влияния
- Заблокированные СЗИ без обхода
- Небезопасные шифры без эксплуатации
- Отсутствие SSL / best practices
- Дубликаты
- Перебор без существенно более эффективного метода
