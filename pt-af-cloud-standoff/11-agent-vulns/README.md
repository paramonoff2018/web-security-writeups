# Agent Vulnerabilities — PT AF Cloud

## Что ищем
Уязвимости в агенте, border-компоненте или механизмах применения политик.

## Три подкатегории (из правил PT)

### 1. DoS-safe PoC (только тестовый тенант)
- Отказ в обслуживании агента: массовый рестарт, зависание, утечка ресурсов
- Прекращение обработки трафика
- Перевод защищаемого ресурса в состояние «без фактической защиты»
- **⚠️ Только безопасный PoC в тестовом контуре, без реальных клиентов**
- **⚠️ Никаких реальных DoS-атак** — только воспроизведение в тестовом tenant

### 2. Утечка данных клиента из клиентского контура
- Содержимое / фрагменты HTTP-трафика
- Заголовки, cookies, токены
- Ключи, connection string
- Конфигурации, политики защиты
- Логи, дампы, telemetry
- Сведения о внутренней топологии

### 3. RCE / escape / pivot в агенте
- Выполнение произвольного кода
- Выход из sandbox / container
- Повышение привилегий
- Чтение локальных секретов
- Изменение правил обработки трафика
- Использование агента как proxy / pivot
- **⚠️ Только в выделенном тестовом tenant/agent, без реальных клиентских приложений, сетей, учётных данных**

- Логи агента
- Взаимодействие с border / control plane

## Векторы
- **Локальный API агента без аутентификации:** `curl localhost:PORT/admin`
- **Path traversal в логах / конфигах:** чтение `/etc/passwd` через агент
- **Symlink-атака:** подмена конфига агентом
- **Race condition при обновлении:** подмена бинаря
- **Небезопасные права:** world-writable конфиги / сокеты
- **Утечка в логах:** cookies, токены, тела запросов в открытом виде
- **Sandbox escape:** через `/proc`, `ptrace`, `mount`
- **Pivot:** агент как proxy к внутренней сети
- **Supply chain:** вредоносное обновление (только PoC в тестовом тенанте)

## Ограничения PT
- **Никаких reverse shell с persistence**
- **Никаких cryptominer'ов**
- **Никаких destructive payload'ов** вне тестового тенанта
- **Никакого pivot в реальную инфраструктуру**
- PoC — только в выделенном тестовом tenant/agent

## Инструменты
- Ghidra / IDA (реверс)
- `strings`, `file`, `ldd`, `checksec`
- `curl` к локальным эндпоинтам
- `strace` / `ltrace` (если есть доступ)
- `docker` / `nsenter` (для sandbox-escape PoC)
- `interactsh` (OOB)
