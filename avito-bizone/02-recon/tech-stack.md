## Инструменты для определения
- `curl -I https://domain`
- `curl -v https://domain`
- `whatweb https://domain`
- `wappalyzer` (браузерное расширение)
- `httpx -probe -tech-detect -u https://domain`
- `nmap -sV --script http-headers <IP>` (если есть IP в скоупе)
