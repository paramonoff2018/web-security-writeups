# Privilege Escalation — Avito

## Что ищем
Повышение привилегий: пользователь → модератор → админ; горизонтальное — к чужому аккаунту.

## Векторы
- **Вертикальная эскалация:**
  - Mass assignment: `"role":"admin"`, `"is_moderator":true` в update-профиле
  - Подмена JWT-claim (`role`, `is_admin`)
  - Обход проверки роли на API (UI скрывает, API — нет)
  - IDOR в админ-эндпоинтах
- **Горизонтальная эскалация:**
  - IDOR к чужому аккаунту (пересекается с 04-idor)
  - Захват чужого объявления через API
  - Подмена user_id в запросе
- **Через HR-системы:**
  - Роль сотрудника → HR → админ
  - Доступ к чужим резюме / зарплатам / документам
- **Через мобильные приложения:**
  - Debug-флаги в APK/IPA
  - Скрытые эндпоинты для внутренних сотрудников

## Out-of-scope
- Перебор ID пользователей
- Enumeration имён

## Инструменты
- Burp Autorize, AuthMatrix
- jwt_tool
- MobSF (анализ APK/IPA)
- ffuf по скрытым эндпоинтам
