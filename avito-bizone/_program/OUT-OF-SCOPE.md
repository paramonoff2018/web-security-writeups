# Avito — Out-of-scope

> Полный список уязвимостей, которые НЕ рассматриваются программой.
> Держи в голове: за них не платят и их можно не репортить.

## НЕ рассматривается (типы уязвимостей)
- Сообщения от сканеров безопасности без анализа и PoC
- Информация об устаревших/уязвимых версиях ПО без примера эксплуатации
- Отсутствие best practices / защитных механизмов без демонстрации уязвимости
- Недостатки парольных политик
- Раскрытие информации без значительного риска
- Self-XSS (не позволяющие атаковать другого пользователя)
- Недостатки SSL/TLS
- Clickjacking
- Подмена содержимого страницы без модификации HTML/CSS
- Уязвимости только в устаревших браузерах
- Session hijacking, session timeout
- Отсутствие заголовков безопасности HTTP (X-Frame-*, X-Content-*, CSP, HSTS, HPKP) и флагов cookies
- Отсутствие SPF, DKIM, DMARC
- Перебор ID объявлений и пользователей (enumeration без impact)
- Перечисление имён пользователей / email
- Уже известные / найденные внутренним тестированием / ранее сообщённые

## Запрещено (действия)
- DoS/DDoS, нарушение доступности сервисов
- Тестирование сервисов вне scope (платёжные шлюзы, сайты-партнёры)
- Физический доступ, фишинг, социальная инженерия
- Использование уязвимости за пределами составления PoC
- Разглашение конфиденциальной информации

> Сетевой список запрещённых хостов — см. `out_of_scope.txt` в корне проекта.
