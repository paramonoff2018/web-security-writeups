# Avito — Правила программы

> Полный текст — в файле «Правила программы.txt» (корень репозитория).
> Ниже — краткая выжимка для быстрого доступа.

## Главное
**Не проверяйте уязвимости на чужих аккаунтах и не затрагивайте других пользователей и работоспособность платформы.**

## Рассматриваемые уязвимости
RCE (server-side), SQLi, XXE, SSRF, Broken Auth & Session Management,
XSS, IDOR, Privilege Escalation, ошибки авторизации, open redirect
(без промежуточной страницы), обход лимитов бесплатных операций,
утечки ПДн (телефоны, VIN, платёжка).

## Запрещено
- DoS/DDoS, нарушение доступности
- Тестирование вне scope (платёжные шлюзы, партнёры)
- Физический доступ, фишинг, соц. инженерия
- Использование уязвимости за пределами PoC
- Разглашение конфиденциальной информации
