# Access Control — Avito

## Что ищем
Ошибки механизма авторизации, Broken Access Control, вертикальная/горизонтальная эскалация.

## Векторы
- **Вертикальная эскалация:** user → moderator → admin, обход ролевой модели
- **Горизонтальная эскалация:** доступ к чужим объявлениям, чатам, платежам (пересекается с IDOR)
- **Force browsing:** доступ к админ-эндпоинтам без прав
- **Метод-подмена:** GET→POST, POST→PUT, X-HTTP-Method-Override
- **Path traversal в API:** `/api/v1/users/me/../admin`
- **Пропуск авторизации на уровне API-gateway:** прямой вызов внутреннего сервиса
- **Mass assignment:** подмена роли через тело запроса (`"role":"admin"`)

## Out-of-scope
- Перебор ID объявлений/пользователей
- Enumeration имён/e-mail
- Раскрытие информации без значительного риска

## Инструменты
- Burp Autorize, AuthMatrix
- Postman для API-флоу
- ffuf по скрытым эндпоинтам
