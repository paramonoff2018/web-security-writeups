# Limit Bypass — Avito

## Что ищем
Обход механизма ограничения лимитов бесплатных операций (явно в перечне Avito).

## Где искать
- Бесплатные объявления (лимит на категорию, на аккаунт)
- Поднятие объявлений (bump / поднятие в поиске)
- Продвижение (выделение, VIP) — бесплатные слоты
- Сообщения в чате (лимит на количество)
- Публикация отзывов
- HR-системы: лимит вакансий, откликов, резюме
- API-квоты (rate limit на бесплатном тарифе)

## Векторы обхода
- **Параллельные запросы:** race condition (отправить N запросов одновременно)
- **Дублирование:** отправить один и тот же запрос с разными `Idempotency-Key`
- **Подмена идентификатора:** другой аккаунт, другое устройство, другой IP (не делай массово!)
- **Обход на уровне API vs UI:** UI блокирует, а прямой API-вызов — нет
- **Отрицательные значения:** `limit=-1`, `quantity=0`
- **Переполнение:** `quantity=999999999`
- **Обход через GraphQL:** batch-запросы, aliases
- **HTTP/2 multiplexing:** много запросов в одном соединении

## Out-of-scope
- Отсутствие rate limit без существенно более эффективного метода (правило Avito)
- Обычный перебор (brute force)

## Инструменты
- Burp Turbo Intruder (race condition, single-packet attack)
- Burp Repeater (параллельные вкладки)
- Postman / curl для API

## Не делать
- Не создавать массово объявления (это спам и нарушение правил)
- PoC — 1–2 лишних операции, не 100
- Не обходить лимиты на платных тарифах (это не «бесплатная операция»)
