# Info Disclosure — Avito

## Что ищем
Утечка конфиденциальной информации (явно в перечне Avito, с уточнениями).

## In-scope (платят)
- **Утечка личной и платёжной информации пользователей**
- **Утечка реальных номеров телефонов**
- **Возможность запросить телефон без отдельных запросов к соответствующим эндпоинтам**
- **Возможность узнать телефон из объявлений в статусах «закрыт» / «на модерации»**
- **Утечка полных VIN-номеров объявлений авто вместе с другими ПДн** (autoteka.ru, авто-категория)

## Out-of-scope (НЕ платят)
- Раскрытие информации без значительного риска
- Enumeration имён / e-mail
- Перебор ID объявлений / пользователей
- Версии ПО, IP, DNS, заголовки без эксплуатации

## Где искать
- API-ответы с «лишними» полями (phone, email, address, passport, card)
- GraphQL: запрос полей, которые UI не показывает
- Мобильные приложения: API-ответы содержат больше, чем показывают
- Превью объявлений в чате (телефон закрытого объявления)
- Кэш / CDN: старые версии страниц с телефонами
- PDF / отчёты (autoteka): VIN + ПДн владельца
- Логи / debug endpoints
- S3-бакеты со статикой

## Техники
- **Mass assignment в ответе:** добавить `?fields=phone,email` в API
- **GraphQL introspection:** найти скрытые поля
- **Diff API vs UI:** сравнить JSON-ответ и то, что рендерится
- **Кэш-инъекция:** запросить страницу с параметром, кэш отдаст другому
- **VIN-декодеры:** сравнить, что отдаёт autoteka vs публичные сервисы

## Инструменты
- Burp (сравнение ответов)
- GraphQL Voyager / InQL
- curl + jq
