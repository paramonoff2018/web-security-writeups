# Идентификация

## Хедер для всех запросов
```
X-Bug-Bounty: Al_x_Pv
```

## User-Agent (рекомендуемый)
```
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36
```

| Аккаунт | Роль | Email | Телефон | Примечание |
|---------|------|-------|---------|------------|
| User 1 | Обычный пользователь | | | Для IDOR (жертва) |
| User 2 | Обычный пользователь | | | Для IDOR (атакующий) |
| Admin  | Администратор | | | Для PrivEsc |

## Лимиты программы
- Rate limit: не превышать 100 запросов/мин на один эндпоинт
- Запрещено: DoS, социальная инженерия, фишинг
- Допустимо: создание до 2 тестовых аккаунтов (использовать разные сим-карты / почты)
