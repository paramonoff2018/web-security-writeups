# Правила программы Avito Bug Bounty

## In-scope уязвимости
- Server-side RCE
- SQL Injection
- XXE (XML External Entity)
- SSRF
- Broken Authentication / Session Management
- XSS (кроме Self-XSS без impact)
- IDOR (Insecure Direct Object Reference)
- Privilege Escalation
- Ошибки авторизации
- Open redirect (без промежуточной страницы)
- Обход лимитов бесплатных операций
- Утечки ПДн (телефон, VIN, платёжная информация)

## Out-of-scope (НЕ рассматривается)
- Сообщения от сканеров без анализа и PoC
- Информация об устаревших версиях ПО без эксплуатации
- Отсутствие защитных механизмов без демонстрации уязвимости
- Недостатки парольных политик
- Раскрытие информации без значительного риска
- Self-XSS без атаки на другого пользователя
- Недостатки SSL/TLS
- Clickjacking
- Подмена содержимого страницы без модификации HTML/CSS
- Уязвимости только в устаревших браузерах
- Session hijacking, session timeout
- Отсутствие заголовков безопасности HTTP (CSP, HSTS, HPKP, X-Frame-Options и др.)
- Отсутствие SPF, DKIM, DMARC
- Перебор ID объявлений и пользователей
- Перечисление имён / email-ов
- Уязвимости, уже обнаруженные внутренним тестированием

## Запрещается
- DoS/DDoS-атаки
- Исследование сервисов вне скоупа
- Фишинг, социальная инженерия, физический доступ
- Использование уязвимости для доступа к данным пользователей (только PoC)
- Разглашение конфиденциальной информации

## Дополнительные лимиты
- Rate limit: не более 100 запросов/мин на эндпоинт
- Максимум 2 тестовых аккаунта
- Не затрагивать других пользователей платформы
- Не нарушать работоспособность сервисов
